# Veille stratégique mondiale

Tableau de bord hebdomadaire : deux indices mondiaux sur 5 (Stabilité mondiale, Risque de guerre mondiale), sur le modèle du DEFCON (5 = calme, 1 = critique), et un module France (niveau national et trois sous-niveaux : risque extérieur, tension intérieure, alertes officielles). Le calcul suit le modèle v3, figé pour garder la série comparable.

- `index.html` : la page publiée par GitHub Pages ; tout est dans un seul fichier (données, rapport, rendu).
- `data/veille.json` : les données du dernier relevé (indicateurs, sources, scores, historique).

La page est mise à jour à chaque relevé par la tâche planifiée « Veille stratégique mondiale ». Les sources sont ouvertes ; chaque indicateur cite ses sources et sa date.
